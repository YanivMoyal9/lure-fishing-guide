# ארסנל הז׳רז׳ור

אתר סטטי בעברית לדמויי ז׳רז׳ור מהחוף. מותאם לטלפון, לטאבלט ולמחשב; אין צורך בהתקנה, בשרת או בתהליך build.

## האתר החי

**https://yanivmoyal9.github.io/lure-fishing-guide/**

האתר מתפרסם אוטומטית מ־`main` בתיקיית השורש באמצעות GitHub Pages. המאגר הקיים `lure-fishing` והאתר בכתובת `/lure-fishing/` נפרדים ממנו. האתר משתמש בנתיבים יחסיים כדי לפעול תחת תת־הנתיב של GitHub Pages. אפשר לפתוח את `index.html` מקומית לבדיקה מהירה.

## עריכה

- `script.js` — רשימת 11 הדמויים, טקסט, דגי מטרה, חודשי עונה וסינון.
- `styles.css` — צבעים, פריסה ועיצוב רספונסיבי.
- `index.html` — מבנה העמוד ומטא־דאטה.
- `assets/lures/` — התמונות שהיו מוטמעות באתר הקודם שלך, כעת בקבצים מקומיים.
- `assets/shore-hero.webp` — תמונת פתיחה שנוצרה לעיצוב החדש.

בחירה בחודש מסננת רק דמויים שעבורם נמסרו חודשים מדויקים בטקסט המקורי. דמויים אחרים נשארים זמינים כשהחודש מוגדר ל״כל השנה״; התווית שלהם אומרת ״עונה לא הוגדרה״ כדי שלא להציג טווח עונה לא מאומת.
